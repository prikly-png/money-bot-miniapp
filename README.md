# money-bot-miniapp

Страница Telegram Mini App для личного бюджета. Здесь лежит **только вёрстка**:
ни цифр, ни ключей, ни доступа к таблице.

Данные страница берёт из Google Apps Script, и он не отдаёт ничего без
подписи Telegram (`initData`), выданной конкретному владельцу. Знать адрес
скрипта недостаточно.

## ⚠️ Здесь не правят

Это зеркало. Источник истины — приватный репозиторий `money-bot`,
файл `miniapp/index.html`. Правки, сделанные тут, будут затёрты
при следующей синхронизации.
